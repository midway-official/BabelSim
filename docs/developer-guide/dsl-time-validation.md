## 初始化接口续轮：实现与源码边界

续轮基线为 `b40fc3836105d0d88ee66bedf834374bd181e0e7`，保存其可执行程序用于结果和性能对照。

- 所有命名场统一由 Case 持有；`load/create/fields` 返回稳定引用，`read` 负责配置。删除平面场接口、`homogeneousLike`、隐式 start/validate 入口，没有兼容别名。
- `ConfigurationDescription<Config>::bind` 同时绑定参数描述和 C++ 成员，支持嵌套成员和 optional；普通配置成员不维护另一套默认值。字段角色与初始化来源分开描述。
- 方程直接绑定 `spec.equation(name)`；RANS 显式接收宿主的流体配置和动量数值选项，删除再次读取宿主配置的路径。
- 先完成通量初值和 PISO 可选初始投影，再创建依赖模型、捕获历史。`addHistory` 持有稳定地址的历史，`trackForRollback` 只登记回滚状态；默认推进不创建事务快照。
- `finalizeInitialization` 检查模块要求的场、类型/位置、初始化来源、修正源、方程绑定和离散项、支持的物理边界及配置消费，然后关闭声明。计算场的面边界迹不作为物理 patch 条件检查。
- Case 方程配置读取合并为一个模板实现；既有 Field 数值运算与底层装配未改动。`equ.h` 只增加从方程描述创建方程的重载，`field.h` 只删除旧局部修正场工厂。

与续轮基线比较，`src/core/backend/discretization/geometry/parallel/runtime/internal` 均无差异。PISO 的 `temporalFluxCorrection` 函数也无差异；其物理修正仍属于 PISO，只使用公共时间权重。

入口初始化行数包含注释和空行，从 `SolverResult run...` 到完成初始化调用前；PISO 同时包含可选初始投影，采用相同口径比较：
