# 稳态与瞬态 SIMPLE：1/2/4 rank 并行一致性

检查日期：2026-09-10。基于当前未提交工作区，起点提交 `e112e597172b7fca5956504c4905e19add13d252`。

## 结论

**所有受测组合通过。** 主矩阵 45 次运行、165 个已收敛状态，逐时刻共 110 组 1→2/4 rank
字段比较。Euler 与 BDF2 每个物理时间步都收敛，最终别名与最后时间步一致。
三/四层 ghost 的额外 33 组比较也通过。没有发现本组算例上的串并行解不一致、缺分片、
错误物理时间或分区造成的提前成功。

结果按全局单元 ID 比较全部 U 分量和 p，保留原压力参考，不作压力均值平移以缩小误差。
逐分量阈值事先固定为 `abs(a-b) <= 5e-6 + 5e-6*max(abs(a),abs(b))`。
除退出 0 和日志收敛外，还逐项复核终端 mass/dU/dP/rU 是否达到各 case 的配置阈值。
检查字段有限性、完整 ID 覆盖、rank 数、metadata 物理时间及逐单元八顶点几何一致性。

## 算例和数值设置

- 原方腔与原 Poiseuille 的稳态保留仓库配置，不根据 rank 单独调参。方腔使用
  Green–Gauss / linearUpwind；通道使用 Green–Gauss / upwind，均为正交扩散。
- 三维方腔采用 8×8×6 单元、全壁面、顶盖速度 (1,0,0)，LeastSquares / upwind /
  orthogonal，存在三维速度分量；未把二维结果复制成三维。
- 扭曲方腔采用 10×8×6 单元，坐标变换 x'=x+.18y+.08y(1-y)sin(πz)，y'=y，z'=z。
  顶盖保持平面且速度切向，采用 corrected 插值、Green–Gauss、linearUpwind、corrected
  扩散及两次非正交修正；分别使用 ghostLayers 3 和 4。
- 每种几何分别运行稳态、Euler、BDF2，每项使用 1/2/4 rank。
  瞬态从静止速度开始，dt=.01、t=.01/.02/.03/.04/.05；BDF2 首步 Euler。
  两种瞬态格式均收紧内层线性容差至 atol=1e-15、rtol=1e-11，dU/dP/rU 门槛为 1e-8；
  所有 rank 使用同一输入。测试对逐时间步压力一致性提出更严格的求解要求，未放宽比较阈值。
