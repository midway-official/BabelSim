# 01 产品与工作流程

[用户手册](README.md) · 下一章：[安装与构建](installation.md)

## 产品用途

BabelSim 是基于单元中心有限体积法的 C++17 求解软件与开发框架。用户通过文本算例文件选择求解器、提供网格与初始场、设置物理参数和数值方法；软件在串行或 MPI 环境中计算，并将单元场保存为可继续计算和后处理的数据。

交付内容包括求解程序、后处理程序、公开 C++ 接口、示例算例、测试与文档，以及本地构建所需的 PETSc、Eigen 和 Hypre 源码。PETSc 负责生产线性系统的矩阵、向量、Krylov 求解和预条件；Eigen 用于局部数值计算。

## 当前提供的能力

| 功能 | 使用入口 |
| --- | --- |
| 常系数热传导及体积热源 | `solver heat` |
| 给定速度下的标量对流扩散 | `solver transport` |
| 不可压缩稳态流动 | `solver simple` |
| 不可压缩瞬态 SIMPLE 与 PISO | `solver transientSimple`、`solver piso` |
| 层流与 SA、kOmega、kEpsilon 闭合 | 流动求解器的 `physics` 字典 |
| 显式面连接的多面体网格、MPI 分区与幽灵层 | `BABELSIM_MESH 3` 输入 |
| Euler、BDF2 时间离散，逐方程/逐项空间离散 | `methods.bs` |
| 分区单元 CSV、几何导出、VTK/Tecplot 后处理 | `babelsim-post` |
| 外部求解器链接与内置求解器注册 | `include/babelsim` 公开接口 |

当前依赖源码集针对 CPU、MPI、实数双精度构建。GPU、其他 PETSc 外部包及额外 Eigen 模块需要补充相应源码与构建配置。现有正式求解器没有提供可压缩流、多相流、移动网格或通用任意 PDE 配置语言；新方程通过 C++ 开发接入。

## 从输入到结果

```mermaid
flowchart LR
    A[准备网格和初始场] --> B[设置物理与数值字典]
    B --> C[启动求解器]
    C --> D[检查退出码和收敛日志]
    D --> E[导出并分析指定时刻]
    E --> F[比较网格、时间步和物理参考]
```

一次完整计算应当保留输入文件、程序构建信息、启动命令、退出码、日志和关注量。运行名用于区分结果，不能替代输入版本记录。

## 单位与数据解释

BabelSim 不自动解析单位或进行量纲换算。建议全部使用 SI 单位，并确保几何、时间、密度、黏度、热参数及源项相互一致。流动求解器中的 `p` 是压力，动量方程使用 `grad(p)`，不是自动除以密度后的运动学压力。`dynamicViscosity` 是动力黏度；RANS 输出 `mut` 也采用动力黏度含义。

对流面通量 `phi` 采用沿面法向、乘面面积后的积分通量。结果 CSV 中保存的是单元场值，而不是面通量或单元积分值。

## 验证与适用性

软件构建成功、线性方程收敛、时间步被接受和物理结果可信是不同层次的结论。尤其对于非定常流动，小质量误差不能证明时间步充分小，也不能证明涡脱落、湍流统计或工程载荷正确。使用者需要独立比较网格、时间步、边界位置与实验或解析参考。

目前向量 `symmetry` 的隐式扩散装配存在切向分量验证需求；涉及滑移壁面或斜对称面时，应增加针对方向和网格的回归。纯 Neumann 标量方程的参考值处理也不会替代源项与边界通量的相容性检查。具体说明见[网格与边界条件](mesh-and-boundaries.md)和[开发验证指南](../developer-guide/verification.md)。
