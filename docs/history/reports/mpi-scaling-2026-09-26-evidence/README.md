# MPI scaling study evidence

> 历史开发记录：保留原报告的接口、命令、数据与结论，只用于追溯对应时期的工作。
> 不作为当前实现或性能的使用说明；现行文档见 [文档中心](../../../README.md)，归档范围见 [历史索引](../../README.md)。

This directory keeps the measurements after the temporary case/result tree was removed.

- `scaling-summary.csv`: median `T_p`, speedup, and efficiency used in the report.
- `run-attempts.csv`: one record per measured MPI run, including rank time spread and setup/output timings.
- `rank-metrics.csv`: per-rank solve timings, Krylov counts, partition counters, and phase timers.
- `raw-metadata/`: original benchmark harness metadata for all measured cases, including exact commands, case/input SHA-256 manifests, per-rank performance JSON, host/runtime facts, and the 5m unsuccessful attempt.
- `case-inputs/`: small case dictionaries and initial fields. Large mesh files are excluded; they can be regenerated by the checked-in generators, and their original SHA-256 values remain in raw metadata.
- `study-evidence.json`: experiment scope, hardware/runtime, timing definition, case manifests, and the 5m attempt summary.
- `five-million-attempt.txt`: human-readable record of the 5,030,912-cell initialization/memory limit.

The generated mesh formula is `cells=2*n^3`. The measured sizes used `n=37, 63, 80, 136`; the warped cases used `--warp 0.15`, with an additional unwarped `n=37` control. The flow dictionaries were derived with `tools/generate_mpi_flow_case.py` from the matching `n=37` and `n=63` meshes. The exact source generator code is in `tools/generate_mpi_scaling_case.py` and `tools/generate_mpi_flow_case.py`.

For a fresh reproduction outside the repository tree, generate a mesh and invoke the existing harness, for example:

```sh
python3 tools/generate_mpi_scaling_case.py \
  --output /tmp/new-mpi-study --grid-n 37 --warp 0.15 --name prism-n37-warped
python3 tools/benchmark_backend.py \
  --case /tmp/new-mpi-study/prism-n37-warped \
  --ranks 1,2,4,8 --repeat 3 --warmup 1 --mode complete \
  --output /tmp/new-mpi-study/results \
  --binary build-petsc/babelsim-solve
```

The flow cases use the same benchmark harness after creating their input with `--solver simple` or `--solver piso`. Reproduction will create fresh outputs and should not write into the preserved evidence bundle.
