# BabelSim 二次开发指南（迁移说明）

本文件保留旧链接。当前 Solver 开发规范已重写为
[solver-development.md](solver-development.md)。请以新文档为准。

新开发者应只使用 `Mesh`、`Field`、边界条件、`fvm`、`fvc`、`Case`、`solve()` 与 `diagnostics`；
不要在 Physics Solver 中使用 MPI、halo、LDU、SparseAssembly、Eigen 或 Field 底层存储。

新增 Solver 通常只需要一个 `src/physics/<name>/main.cpp` 函数，以及显式选择表的一项。
不再需要编写专用 Case reader、运行适配器或并行输出。详见新指南中的完整工作流。
