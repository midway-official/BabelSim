# BabelSim 二次开发指南（迁移说明）

本文件保留旧链接。当前 Solver 开发规范已重写为
[solver-development.md](solver-development.md)。请以新文档为准。

新开发者应只使用 `Mesh`、`Field`、边界条件、`eqn`、`math`、`Case`、`solve()` 与 `diagnostics`；
不要在 Physics Solver 中使用 MPI、halo、LDU、SparseAssembly、Eigen 或 Field 底层存储。

`include/babelsim/` 不发布任何具体 Solver 的类。Heat、Transport、稳态 SIMPLE 和瞬态 SIMPLE
都只是公共 Framework API 的使用者，其私有头位于 `src/physics/`，不能作为二次开发依赖。
新 Solver 应学习它们的方程或算法组织方式，而不是包含、继承或包装其实现类。

新增独立 Solver 通常只需自己的一个源文件：PDE/算法函数、一行 SolverRegistration 和通用 runApplication 入口。
只用公开头和预编译库，不修改 BabelSim。可选放入 physics 子目录由内置命令构建，不需要集中选择表。
不再需要编写专用 Case reader、运行适配器或并行输出。详见新指南中的完整工作流。
